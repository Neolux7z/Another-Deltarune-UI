_**THIS RESOURCE PACK IS IN VERY EARLY STAGES OF DEVELOPMENT**_

Another Deltarune UI grabs the idea of having the Deltarune UI in Minecraft and gives it its own twist using my interpretation on how a Deltarune inspired UI would be (following Minecraft's limitations).

This resource pack was made with the intention to not only be a love letter to Deltarune but also to the Deltarune community.

Apart from the UI this resource pack also includes some hidden _**easter eggs**_ through splash texts and _other_  things.

This GitHub page will ONLY be used for sending bug reports or feature request.
